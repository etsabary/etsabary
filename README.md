# Eldad Tsabary

I'm a researcher and developer interested in how AI models make decisions, where they fail, and how they can be useful in real software. I build practical tools and use experiments to examine those questions.

My current public work compares models on shared text and image tasks, looking at accuracy alongside response time and cost. I care about explaining what a result means for a particular task, including the conditions under which a model should not be trusted.

## Selected work

- [Text decision benchmark](https://github.com/etsabary/jev-1.14-comparison-benchmark): Jev, Luna and budget LLMs evaluated on the same 1,136 questions.
- [Image decision benchmark](https://github.com/etsabary/visual-decision-benchmark): 200 questions per model using photographs, diagrams and visual constraints.
